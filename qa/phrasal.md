검토했지만 그대로 둔 것
- H3P4(up)·H6P4(for)·H8P4(up)·H11P4(out)·H12P4(up) order 함정: 넣으면 문법상으론 다른 구동사(turn it up, look for, put it up, give out, fill it up)가 되지만 **뜻이 ko 와 달라서** 정답이 될 수 없음 → 뜻을 가리는 좋은 함정이라 유지(같은 뜻이 되는 H10P4 think it out 만 바꿈).
- H6P5·H6P6·H2P7·H4P7·H10P5 fix 의 틀린 문장은 영어로는 성립하는 다른 뜻 문장 → prompt 를 「한국어 뜻에 맞게」로 바꿔 무엇을 고칠지 분명히 함.
- build/order 의 동의어 답(colleagues, due to …)은 카드로 만들 수 없어 추가하지 않음.

## 질문
1. **order 함정이 「다른 뜻의 맞는 구동사」가 되는 경우**(위 5개): 지금은 ko 로 뜻이 정해지니 오답이 맞다고 보고 유지했어요. 함정은 문법 실수(wakes, to, gave …)로만 쓰는 게 좋을지 정해 주세요.
2. **type 문제에서 목표 구동사 대신 같은 뜻 낱말**(wear, switch on, cancel, resemble, postpone, quit …)도 정답 처리했어요. 「꼭 구동사로 써야 정답」으로 하려면 prompt 에 「구동사로」를 밝혀야 해요 — 어느 쪽이 좋을까요?
3. **HB1 보스**: 알람을 못 들은 늦잠인데 대표 답이 I slept in. 이에요(구어에서 흔해서 유지, H1 에 oversleep 설명 추가). 대표 답을 I overslept. 로 바꿀까요? (그러면 oversleep 을 H1 에서 정식으로 가르쳐야 해요.)
4. **채점기(core — 제 파일 아님)**: ① `7am`(붙여 쓴 am)은 `7 am`·`7 a.m.` 과 같게 안 봐요. ② 명사 뒤 's(`The meeting's been …` = meeting has)는 같게 안 봐요(대명사만 됨). 이번엔 answer 에 직접 넣어 막았어요 — 채점기에서 처리할지 검토 부탁해요.
