# QA 기록 — basic 챕터 7 「실전」 (c7.js: E35 · E36 · E37)

이번 작업: 지난 QA(qa/basic-b.md 「질문」 1·2번)에 따라 E35 일기를 자유 쓰기로 바꾸고, E36 자기소개에 자유 쓰기 2문제를 더했어요. E37 은 지난 QA 그대로예요(다시 훑어봤고 고칠 것 없음).
검사: `node tools/stamp.mjs && node tools/validate_content.mjs && node tools/check_answers.mjs` → FAILS 0 · 경고 0.
화면 시험: `python3 tools/play.py --course basic --font 3`(글자 「아주 크게」) → FAILS 0.
학습자 답 시험: 새 free 7문제에 학습자가 쓸 법한 내 이야기 답 약 25개(통과해야 할 답 + 조건이 빠져 떨어져야 할 답)를 Grader.free 로 확인했어요.

free 문제의 원칙은 qa/write.md 와 같아요: prompt 에 「내 하루·내 이야기」임을 밝힌 과제, ko 는 ○○ 빈칸이 있는 한국어 틀(화면이 「뜻:」으로 보여 주기 때문), need 는 레슨의 목표 표현만, minWords 는 축약형을 풀어 센 낱말 수, 모범 문장 3개(조건 통과·흔한 실수 규칙 안 걸림 확인).

## 1. E35 「내 하루 일기 5문장」 — 모범 문장 번역(type) → 자유 쓰기(free)

| id | 전 (정해진 문장) | 후 (free) — need / minWords |
|---|---|---|
| E35P5 | 오늘은 바쁜 하루였어요. | 내 오늘 하루 한 줄 평 — [Today was / It was / I had a] / 3 |
| E35P6 | 나는 7시에 일어났어요. | 내가 몇 시에 일어났는지 — [got up / woke up] + [at] / 4 |
| E35P7 | 점심은 미나랑 먹었어요. | 오늘 누구와 무엇을 했는지 — [with / alone / by myself] / 4 (혼자였던 사람도 쓸 수 있게) |
| E35P8 | 퇴근하고 헬스장에 갔어요. | 저녁에 어디에 갔는지 — [went / stayed] / 3 (집에 있었던 사람은 I stayed home.) |
| E35P9 | 피곤했지만 기분은 좋았어요. | 내 기분으로 마무리 — [I was / I felt] / 3 (but 은 권장만) |

title(「일기 1/5」~「5/5」)은 그대로 두었어요. 지난 QA 에서 넣은 많은 허용 답은 free 에선 필요 없어서 대표 모범 문장 3개로 정리했어요(첫째는 예전 대표 답 그대로). 이 레슨 3쪽 팁(「낱말만 내 하루로 바꿔 보세요」)과도 이제 맞아요.

## 2. E36 「자기소개 1분 말하기」 — 자유 쓰기 2문제 추가 (카드 배열 뒤, 따라 말하기 앞)

| id | 문제 | need / minWords |
|---|---|---|
| E36P10 (새로) | 내 자기소개 1/2: 어디 출신이고 어디 사는지, 무슨 일을 하는지 (학생이면 I'm a student.) | [I'm from / I live in] / 8 |
| E36P11 (새로) | 내 자기소개 2/2: 취미(I like to …) + 영어를 배우는 이유(because …) | [like / love / enjoy / I can] + [because] / 12 |

배열 문제(P2~P5)로 틀을 익히고 → 내 이야기로 쓰고(P10·P11) → 따라 말하기(P6~P9) 순서가 돼요. 문제 id 는 기존 진도 기록이 깨지지 않게 새 번호(P10·P11)를 쓰고, 배열 안에서 자리만 P5 뒤에 넣었어요.

## 3. 그 밖
- 문제 묶음 주석을 「E35 — 일기 (조각 연습 → 내 하루 5문장을 한 줄씩 자유 쓰기)」, 「E36 — 자기소개 1분 (배열 → 내 자기소개 자유 쓰기 → 말하기)」로 바꿈.

## 질문

1. **E36 이 이제 문제 11개예요**(content-guide 기준 7~9개). 듣기 1 · 카드 배열 4 · 자유 쓰기 2 · 따라 말하기 4. 줄인다면 따라 말하기 중 E36P6(하는 일)·E36P7(출신)을 빼는 게 가장 덜 아까워요(같은 문장을 P3·P4 배열에서 이미 만들어요). 빼도 될까요? (진도 기록이 있는 id 라서 제가 임의로 지우지 않았어요.)
2. 자유 쓰기 화면이 ko 를 「뜻: …」으로 보여 주는 문제, 「꼭 넣을 표현」 칩이 줄바꿈되지 않는 문제는 qa/write.md 「질문」 1·2번과 같아요(core 파일이라 손대지 않았어요).
