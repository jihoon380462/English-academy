# 만들기 우선(Create-first) 학습 개편 기획서

> 2026-11-06 · 상태: **기획 — 사용자 확인 대기** (확인 전에는 코드·콘텐츠 안 바꿈)
> **사용자 결정(같은 날): 첫 단계로 「🧩 조합 말하기」(원형 낱말 표 + 문법 설명만 보고 스스로 조합, 음성은 우선 뺌)를 먼저 만듦 → v0.5.0.** 나머지(거꾸로 사다리 등)는 써 본 뒤 결정.
> **2026-11-08 사용자 결정: 「내가 만든 문장」 시스템(개수·목록·뱃지) 자체가 불필요 → 아래 3-5 「📒 내 문장 덱」·3-7 「이번 주 만든 문장」·뱃지 「내 문장 100」은 하지 않음.** 만들기는 하되 세거나 모으지 않아요.
> 계기(사용자): 「모든 학습은 내 스스로 무언가를 만들 수 있어야 한다. 강의가 끝나면 못 하는 경우가 왕왕 있다. 화면에 보이는 내용을 repeat 하는 것보다 머릿속에 있는 내용을 create 하는 게 더 도움이 된다.」

## 1. 문제: 지금 사이트는 「보고 고르기」가 대부분

v0.4.0 문제 2,164개를 「학습자가 정답을 어디서 가져오나」로 나눴어요.

| 구분 | 유형 | 개수 | 비율 |
| --- | --- | --- | --- |
| 보고 고르기·맞추기 (정답이 화면에 있음) | choice 382 · listen 237 · order 256 · build 118 · match 108 · fill 153 | 1,254 | **58%** |
| 따라 하기 (보이거나 들리는 걸 그대로) | speak 241 · dictation 103 | 344 | **16%** |
| 머리에서 만들기 | type 347 · fix 195 · free 24 | 566 | **26%** (자유 쓰기 1%) |

복습도 같아요. 문장 덱 L 카드(듣고 뜻 떠올리기), 단어장 F 카드(단어 → 뜻)는 **알아보기**고, P 카드(뜻 → 영어로 말하기)는 만들기지만 **스스로 채점**이에요. 단어장 철자 카드는 예문 빈칸에 **낱말 하나**만 넣어요.

결과: 레슨 안에서는 다 맞히는데, 빈 화면에서 「토요일에 시간 돼?」를 영어로 못 만드는 상태가 생길 수 있어요. 강의를 따라 칠 때는 되는데 혼자서는 손이 안 움직이는 코딩 공부와 같은 상황이에요.

근거: 기억은 **꺼낼 때** 강해져요(인출 연습, retrieval practice). 남이 준 걸 알아보는 것보다 **스스로 만들어 낸 것**이 오래 남아요(생성 효과, generation effect). 조금 어렵게 느껴지는 연습이 오히려 오래 가요(바람직한 어려움, desirable difficulty).

## 2. 원칙 (SPEC 1장에 추가)

1. **먼저 만들고, 막히면 도움.** 모든 연습은 빈칸(빈 입력칸·빈 마이크)에서 시작해요. 보기·조각·첫 글자는 「막혔을 때 내려가는 사다리」예요.
2. **보고 → 가리고 → 만들기.** 새 문장은 설명 페이지에서 한 번 보고 들어요. 문제에서는 가려진 상태로 다시 만들어요.
3. **똑같이 반복 말고 바꿔서 만들기.** 배운 문장의 주어·시제·부정·상황을 바꿔 새 문장을 만들어요. 외운 문장을 그대로 다시 쓰는 건 repeat 이에요.
4. **내 이야기로 끝내기.** 레슨과 챕터는 항상 「내 문장」 과제로 끝나요. 정답 하나를 맞히는 대신 내 상황을 영어로 써요.
5. **복습도 만들기.** 복습 카드의 기본은 「뜻 → 영어로 만들기(입력·말하기)」예요. 알아보기 카드는 보조로만 둬요.
6. **목표 지표: 학습 시도의 60% 이상이 「만들기」**(지금은 26%). 통계에 저장해서 홈에서 보여 줘요(「이번 주 내가 만든 문장 123개」).

## 3. 바꾸는 것

### 3-1. 문제 엔진: 「거꾸로 사다리」 (가장 중요)

지금 사다리는 아래에서 위로 올라가요(조립 → 배열 → 타이핑 → 말하기, SPEC 3-2). 이걸 **위에서 시작해서 막히면 내려가는 방식**으로 바꿔요.

| 단계 | 화면 | 채점 → Anki 평가·XP |
| --- | --- | --- |
| 0. 만들기 | 한국어 뜻 + 빈 입력칸(또는 🎤) | 맞히면 **쉬움**, XP 100% |
| 1. 힌트 | 성분 색 칸만(`[S][V][O][M]` 빈칸 개수) + 핵심 낱말 1개 | **좋음**, XP 80% |
| 2. 첫 글자 | `S___ y__ t_____` | **어려움**, XP 60% |
| 3. 조각 배열 | 섞인 카드(+ 함정) — 지금의 order | **다시**(곧 다시 나옴), XP 40% |
| 4. 정답 보기 | 정답 + 따라 쓰기 1회 | **다시**, XP 0 + 10분 뒤 다시 |

- 「💡 막혔어요」 버튼 하나로 한 단계씩 내려가요. 지금의 힌트 버튼이 이 역할을 맡아요.
- 단계 3에서 맞혀도 「다시」로 평가해서 곧 **만들기(0단계)로 다시** 나와요. 고르기로 넘어간 문장은 「아직 못 만드는 문장」으로 남아요.
- 콘텐츠를 다시 쓰지 않아도 돼요. 문장(정답 `en` + 뜻 `ko` + 성분 `roles`)이 있는 문제는 자동으로 0~4단계를 만들 수 있어요. 확인해 보니 order 256 · build 118 · type 347 · speak 241, **모두 962개(44%)가 뜻(ko)과 정답 문장을 다 갖고 있어서** 바로 바꿀 수 있어요. 성분 색(roles)이 없는 문제는 1단계 색 칸을 낱말 수 칸으로 대신해요.
- **같은 문장을 다른 유형으로 여러 번 내던 문제(조립 → 배열 → 타이핑)는 하나로 합쳐요.** 문제 수는 줄고 문제 하나하나는 깊어져요.

### 3-2. 알아보기 문제의 자리

| 지금 유형 | 바뀌는 자리 |
| --- | --- |
| order·build | 거꾸로 사다리 3단계(조각)로 흡수 |
| choice(뜻 고르기·문법 고르기) | 레슨 **앞쪽 「확인 퀴즈」** 1~2개로만 남김 (설명을 읽었는지 확인) |
| match | 레슨 맨 앞 워밍업으로만 (낱말 뜻 빨리 훑기) |
| fill(보기 있는 빈칸) | 보기 없는 빈칸 입력으로 바꿈(머리에서 꺼내기), 보기는 1단계 도움으로 |
| listen(듣고 고르기) | **듣고 영어로 받아쓰기 → 뜻 쓰기**로 무게를 옮김, 고르기는 처음 한 번만 |
| speak(따라 말하기) | **뜻 보고 말하기**(문장을 안 보여 줌)가 기본, 따라 말하기는 4단계(정답 보기)에서만 |
| dictation | 그대로 둠 (소리 → 글자로 꺼내기) |

### 3-3. 새 문제 유형 2개

**① 바꿔 쓰기 `remix`** — 모범 문장 하나 + 바꾸는 조건 → 새 문장 만들기. 정답이 정해져 있어서 자동 채점이 정확해요.
```
모범: I'm free on Saturday.
조건: 친구(she)가 일요일에 시간 된다고
정답: She's free on Sunday. | She is free on Sunday.
```
조건 종류: 주어 · 시제(과거·미래) · 부정 · 질문으로 · 높임(Could you…) · 상황(장소·시간) 바꾸기. 레슨마다 2~3개 넣어요. 콘텐츠 스키마: `{ type: 'remix', model, change, answer: [...] }`

**② 내 문장 `mine`** — 지금의 free(자유 쓰기)를 넓혀요. 「배운 패턴으로 **내 이야기** 문장 2개」.
- 자동 채점은 형식까지만 해요. 꼭 넣을 표현(need), 최소 낱말 수, 흔한 실수 규칙(shared/mistakes.js)을 확인해요.
- 뜻과 자연스러움은 기계가 판단할 수 없어서 아래 셋으로 보완해요.
  1. 모범 문장 2~3개와 나란히 보여 주고 체크리스트로 스스로 점검해요(주어·동사 있나 / 시제 맞나 / 꼭 넣을 표현).
  2. 「📋 AI 첨삭용 복사」 버튼을 둬요. 내 문장과 「고쳐 주고 이유를 한국어로」 지시문을 같이 복사해서 ChatGPT·Claude 에 붙여 넣으면 돼요. 사이트는 정적이라 AI를 직접 부르지 않아요.
  3. 스스로 「맞다고 확인」한 문장만 **내 문장 덱**에 들어가요(3-5).
- **모든 레슨의 마지막 문제**로 넣어요(지금은 24개 → 약 250개).

### 3-4. 복습 카드: 만들기가 기본

| 카드 | 지금 | 바꾼 뒤 |
| --- | --- | --- |
| 문제 복습 `p:` | 같은 문제를 같은 유형으로 다시 | 같은 문장을 **0단계(만들기)부터** 다시 |
| 문장 덱 P (뜻 → 영어) | 말하고 뒤집어서 스스로 평가 | **입력 또는 🎤 → 자동 채점**(Grader.text / speak), 평가 자동 제안 + 사용자가 바꿀 수 있음 |
| 문장 덱 L (듣고 뜻) | 기본 카드 | 보조 카드(설정에서 끌 수 있음, 기본 켬 → 끔으로 바꿀지 결정 필요) |
| 단어장 F (단어 → 뜻) | 기본 | 처음 볼 때만(새 단어 소개) |
| 단어장 R (빈칸 철자) | 낱말 하나 입력 | **예문 전체를 뜻 보고 쓰기**로 한 단계 위(문장 위주 원칙과 맞음) |
| 단어장 C 🆕 | — | 「이 단어로 내 문장 만들기」 — mine 과 같은 채점 |

### 3-5. 내 문장 덱 (내가 만든 걸 복습)

- `mine`·`remix`·챕터 과제에서 만든 문장 중 「맞다고 확인」한 것은 자동으로 **📒 내 문장 덱**에 쌓여요. 카드 id 는 `m:<시각>`이에요.
- 복습할 때는 **내가 쓴 한국어 메모(뜻) → 내 영어 문장 만들기**예요. 남의 예문보다 내 이야기라서 오래 남아요.
- 문장 덱 페이지에 탭 하나를 더 둬요. 고치기와 지우기도 돼요.

### 3-6. 챕터 끝 「백지 과제」 (코딩의 「빈 파일에서 만들기」 자리)

보스 레슨 뒤에 **도움 없는 과제**를 하나 둬요. 예를 들면 「자기소개 5문장」, 「주말 계획 약속 잡기 대화 6줄」, 「어제 있었던 일 이야기」예요.
- 힌트·조각·보기가 없어요. 끝난 뒤에만 모범 답안과 체크리스트를 보여 줘요.
- 🎤 버전도 있어요. 주제를 보고 30초 말하면, 음성 인식으로 받아 적은 글과 낱말 수, 배운 표현을 몇 개 썼는지를 보여 줘요.
- 같은 과제를 1주·1달 뒤에 다시 보여 줘요(Anki 간격). 예전 답과 비교할 수 있게 해서 **늘었는지 눈으로 보이게** 해요.

### 3-7. 통계·보상

- 홈에 「이번 주 만든 문장」 수와 만들기 비율(만들기 ÷ 전체 시도)을 보여 줘요.
- XP 는 만들기가 가장 많아요(단계별 XP 3-1). 고르기만으로 레벨이 빨리 오르지 않게 해요.
- 뱃지: 「도움 없이 10문장 연속」, 「내 문장 100개」, 「백지 과제 첫 완주」.

## 4. 바뀌지 않는 것

- Anki 스케줄러, 저장 키(`eng.*`), 동기화, 코스 구조, 성분 색, 레슨 설명 페이지는 그대로예요.
- 설명 페이지의 예문, 🔊 듣기, 낱말 누르기(입력 단계 = 보고 듣는 단계)도 그대로예요.
- 채점기는 이미 만들기용이에요(축약형·오타·변화형 처리). remix·mine 에 그대로 써요.

## 5. 위험과 대책

| 위험 | 대책 |
| --- | --- |
| 초급자에게 빈칸부터는 너무 어려워서 그만둠 | 사다리 1~3단계가 바로 있고, 「💡 막혔어요」는 벌이 아닌 길이에요(XP는 줄어도 진행은 됨). 기초 챕터 0~1(소리·알파벳)은 듣고 고르기를 유지 |
| 자유 쓰기는 정확히 채점이 안 됨 | remix(정답 있음)를 주력으로, mine 은 형식 채점 + 모범 비교 + AI 첨삭 복사 |
| 정답 변형이 많아 맞게 써도 틀림 처리 | 지금 문제마다 정답 여러 개 + 채점기 정규화가 있음. 만들기 비중이 커지면 오답 로그를 봐서 정답을 넓히는 QA 를 매 릴리스마다 함 |
| 기존 진행(별·클리어)이 꼬임 | 문제 id 를 유지하고, 합쳐지는 문제는 「대표 문제」로 기록을 옮기는 변환 코드를 둠 |
| 만들기는 시간이 더 걸려서 하루 분량이 줄어 보임 | 레슨 문제 수를 줄이고(합치기), 「오늘의 목표」를 문제 수가 아니라 만든 문장 수로 셈 |

## 6. 단계 계획 (각 단계 = QA 후 배포)

| 단계 | 내용 | 범위 |
| --- | --- | --- |
| C1 | **거꾸로 사다리 엔진**(cards.js) + 평가·XP 연동 + 만들기 통계, **기초 코스만** 시범 적용 | 코어 + basic |
| C2 | `remix`·`mine` 유형 + 기초 코스 레슨마다 remix 2개·mine 1개 | 코어 + basic 콘텐츠 |
| C3 | 복습 카드 개편(문제 복습 0단계부터, 덱 P 자동 채점, 단어장 R 문장·C 카드) + 📒 내 문장 덱 | 코어 + deck + words |
| C4 | 챕터 끝 백지 과제(쓰기·말하기) + 다시 풀기 비교 | 코어 + basic |
| C5 | 나머지 9개 코스에 적용(문제 합치기·remix·mine 추가), 코스마다 독립 검수 | 콘텐츠 |

C1 이 끝나면 기초 코스를 직접 써 보고, 방향이 맞는지 판단해요. 맞으면 C2 로 가요.

QA는 단계마다 지금 하는 검사(validate·check_answers·regress·play 봇)를 그대로 돌려요. 여기에 **만들기 시나리오**를 더해요. 봇이 0단계에서 정답 변형(축약형·동의 표현)을 써서 정답 처리되는지, 일부러 막혀서 1~4단계를 차례로 내려가는지, 평가와 XP가 표대로 나오는지 확인해요. 그리고 「만들기 비율」이 목표(60%)를 넘는지도 검사해요.

## 7. 정해 주세요 (★ = 추천 기본값)

1. **알아보기 문제(고르기·짝 맞추기)** — ★ 레슨 앞 확인용 1~2개만 남기고 나머지는 사다리 도움으로 흡수 / 지금 문제 그대로 두고 만들기 문제만 추가 / 완전히 없애기
2. **시범 코스** — ★ 기초 코스 먼저(C1~C2) 써 보고 결정 / 처음부터 전체 코스
