# 콘텐츠 작성 가이드 (모든 코스·덱 공통)

> 스키마 원문: `courses/basic/content.js` 맨 위 주석(코스), `courses/deck/content.js` 주석(문장 덱). 예시: `courses/basic/parts/c1.js`(레슨 E1). 이 가이드는 **품질 기준**이에요.

## 0. 사용자 결정 (꼭 지켜요)
- **문장 위주**: 낱말 하나만 묻지 않아요. 문제·예문·카드는 항상 **완전한 문장** 안에서. (짝 맞추기도 「문장/구 ↔ 뜻」)
- **복습은 Anki**: 레슨 예문(`ex`)은 레슨을 끝내면 자동으로 문장 덱에 들어가 Anki 방식으로 복습돼요 → 예문은 **외울 가치가 있는 자연스러운 문장**으로, `ko` 를 꼭 달아요. (설명용 조각 문장은 `deck:false`)
- 학습자: 영어를 학교에서 배웠지만 손 놓은 한국인 성인(왕초보~중급). 설명은 **~해요체**, 짧고 쉽게, 문법 용어는 처음 나올 때 쉬운 말로(`terms`).
- 예문은 **전부 직접 지은 문장**. 교재·드라마·노래·기사 문장 복사 금지. 실존 인물·브랜드 이름 대신 평범한 이름(Mina, Tom, Jisoo …)과 일반 명사.

## 1. 레슨 구성
- 레슨 1개 = 설명 2~4쪽(`pages`) + 문제 7~9개 + 정리 3줄(`summary`). `minutes` 5~8.
- 쪽마다 `html`(2~4문장 설명, `<p>`·`<b>`·작은 `<table>` OK) + 예문 2~4개(`ex`). 기초 코스는 예문에 `roles`(성분 색)를 적극적으로, 다른 코스는 필요한 곳에만.
- `en` 의 `|` 는 의미 덩어리 경계. `roles` 글자 수 = 덩어리 수. 성분: S 주어 · V 동사(조동사·not 포함 동사 덩어리) · O 목적어 · C 보어 · M 꾸밈말(때·곳·방법) · J 연결어 · Q 질문어(의문사·Do/Does 앞머리).
  - 예: `'Do you|like|coffee?'` + `'Q·S'` 같은 합성 글자는 안 돼요 → `'Do|you|like|coffee?'` + `'Q S V O'`.
- 팁(`tip`)은 쪽당 0~1개.

## 2. 문제 사다리 (한 레슨 안에서 쉬움 → 어려움)
권장 순서와 개수(레슨당 7~9개):
1. `choice` 또는 `listen` 1~2개 (빈칸 고르기는 `q:'I ___ a student.'`)
2. `match` 0~1개 (문장/구 ↔ 뜻 3~5쌍)
3. `build` 1개 (성분 색 슬롯, cards 3~6장, roles 필수, 함정 없음)
4. `order` 1~2개 (cards 4~8장 + distractors 1~2장 — 흔한 실수를 함정으로: is/am, go/goes …)
5. `fill` 또는 `fix` 1~2개 (fix 의 `wrong` 은 학습자가 실제로 하는 실수)
6. `type` 1~2개 (한국어 → 영어 직접 쓰기. **answer 에 자연스러운 다른 표현을 3~6개까지** 넣어요: 어순·동의어·생략 가능한 말)
7. `dictation` 0~1개, `speak` 1개 (레슨 대표 문장)

- 모든 문제: `prompt`(무엇을 하라는지 한 줄), `tags` 1~3개(한국어), `hints` 정확히 3개(방향 → 구체 → 거의 정답/정답).
- `why` 는 오답일 때도 도움이 되는 한 줄 설명(choice·fill·fix 에는 꼭).
- `ko` 는 type·build·order·fix·speak 에 넣어요(사용자가 뜻을 보고 만듦).
- **채점 규칙**(core/grader.js): 대소문자·쉼표·마침표·물음표 무시, 축약형 동치(I'm=I am, don't=do not …, shared/contractions.js), 4글자 이상 낱말 오타 1개 허용. 그 밖의 차이(어순·다른 낱말·관사)는 answer 에 넣어야 정답.
- 카드(cards)는 대표 답(answer[0])을 순서대로 자른 것 — 이어 붙이면 정답이 돼야 해요(check_answers 가 확인). 문장부호는 마지막 카드에 붙여도 돼요.
- 흔한 실수 규칙(shared/mistakes.js)이 **정답 문장**에 걸리면 check_answers 가 실패해요 → 문장을 바꾸거나(드물게) 규칙 쪽이 너무 넓은지 보고해요.

## 3. 보스 = 상황 미션 (챕터 끝)
- 레슨 `{ id:'B<챕터>', boss:true, ... }` (코스별 접두사: 기초 B, 듣기·말하기 TB, 문법 GB, 읽기 RB, 개발자 DB).
- `pages` 1~2쪽: 상황 설정(누구와 어디서 무엇을) + 쓸 표현 미리보기 예문.
- 문제 6~8개, 전부 `boss:true`, 상황 순서대로 이어지는 이야기. 챕터에서 배운 걸 섞어서(listen → order → type → speak …).

## 4. 문장 덱(courses/deck/parts/*.js)
- 덱 1개 = 한 주제, 문장 40~60개. `{ id:'cafe-001', en, ko, key, keyko, note?, alt? }`
- `key` = 이 문장에서 익힐 핵심 표현(덩어리), `keyko` = 그 뜻. `alt` = 같은 뜻의 다른 자연스러운 영어(🗣 카드에서 입력했을 때 정답 처리).
- 쉬운 문장 → 어려운 문장 순서(새 카드는 위에서부터 나와요). 길이 4~12낱말 위주.
- 첫 덱(starter)만 `defaultOn:true`. 나머지는 사용자가 켜요.
